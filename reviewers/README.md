# Insects manuscript reviews

These files preserve the Round 1 reviewer and academic editor comments copied from the journal revision page on 2026-08-21. The comment bodies are transcribed verbatim as displayed, with HTML entities rendered as their visible Unicode characters.

The journal-provided manuscript source was compared with the current [main manuscript](../manuscript.tex). It is an older copy. Its only difference is an earlier version of the CRediT author-contribution statement. The current manuscript includes the two later repository updates to that statement, so the downloaded source, PDF, and BBL were moved to Trash.

Paste-ready text for the three MDPI response fields is in the [portal](portal) directory. Each file includes the complete journal comment followed by the finalized response. The confidential editorial-office note and submission instructions are in [portal-responses.md](portal-responses.md). The typeset point-by-point response remains in `response-letter.typ`.
